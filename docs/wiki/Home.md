# medicine-uams

`medicine-uams` is the WordPress child theme for the UAMS College of Medicine site. It is a child of the `uams-2016` theme: the parent supplies the templates, styles and bundled Advanced Custom Fields (ACF) Pro, and this theme changes the site header and a few styles. WordPress lists it as **Snoqualmie Falls**.

These pages cover installing the theme, what it changes, how to work on it, and what to check when something looks wrong. The repository has no README; the [contributing guide](https://github.com/UAMS-Web/medicine-uams/blob/master/CONTRIBUTING.md) holds the issue-to-merge path.
